# CBMS - Curtain Business Management System

A curtain management system designed for curtain shops to manage sales, production processes, inventory, and revenue.

The system also supports AR visualization, allowing customers to preview curtains in their actual environment before making a purchase.

## Main Stacks

* **Web Frontend:** Angular
* **Mobile Frontend:** Angular + Ionic + Capacitor
* **Backend:** Spring Boot + Java 21
* **AR:** Unity as a Library
